## SessionStart

A session starts or resumes. Reference: <https://code.claude.com/docs/en/hooks#sessionstart>.

- Matcher: how the session started (`startup`, `resume`, `clear`, `compact`, `fork`)
- Decision control: Context only (hookSpecificOutput)
- Output fields: `additionalContext`, `initialUserMessage`, `sessionTitle`, `watchPaths`, `reloadSkills`
- Exit code 2: Shows stderr to user only

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `source` | string | yes | startup, resume, clear, compact or fork |
| `model` | string | no | Active model identifier; not always included |
| `session_title` | string | no | Custom session title, when one is set |
| `seconds_since_last_response` | number | no | On resume or fork: seconds since the last response |
| `context_tokens` | number | no | On resume or fork: tokens the first request re-sends |
| `prompt_cache_likely_expired` | boolean | no | On resume or fork: whether the cache expired |
| `estimated_cache_write_usd` | number | no | On resume or fork: estimated re-cache cost |
